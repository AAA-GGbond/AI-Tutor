# 学迹：学习档案 Demo

使用 Python 标准库 + SQLite，无需安装第三方依赖。数据保存在 `demo/data/learning.sqlite3`，重启后仍保留。

## 启动

在项目目录运行：

```sh
python3 demo/server.py
```

打开 http://localhost:8765 。服务仅监听本机。

## 体验

1. 新建学生，默认选择七年级上学期。
2. 给试卷命名，上传 1～6 张 JPG / PNG / WebP 图片。
3. 点击分析，查看错题及累计学习档案。未配置模型时显示“模拟体验”。
4. 上传另一份图片，观察知识点、题目证据和档案版本累积变化。
5. 用户界面仅包含学习档案、上传试卷、分析记录，无配置入口。

## 制作方配置

打开 http://localhost:8765/admin 使用可视化后台。访问口令在 `demo/data/admin-token.txt`，不要分享给体验用户。后台支持模型接口与密钥、运行模式、提示词文档导入和知识点逐行编辑；保存后下一次分析立即生效，无需重启。密钥留空保留原密钥，也可勾选清除；接口不回显密钥。口令仅在当前后台页面内存中使用，刷新后需要重新登录。

首次读取文件或环境变量作为初始配置。第一次通过后台保存后，以数据库中的制作方配置为准，后续请在后台修改。密钥存储于本机 SQLite（文件权限仅当前用户可读写），不是加密保险库。该后台只供本机 Demo 使用。

也可在首次后台保存前编辑 `demo/prompt.md` 与 `demo/knowledge.json` 作为初始配置。配置不通过用户接口返回或修改。

模型密钥、地址和名称使用下述服务端环境变量。默认自动模式：三项配置完整时使用真实分析，否则使用明确标识的模拟体验。制作方也可设置 `ANALYSIS_MODE=demo` 或 `ANALYSIS_MODE=real` 固定模式，用户无法选择或覆盖。对外真实演示建议设置 `ANALYSIS_MODE=real`，避免缺少配置时切换为模拟结果。

模拟体验不识别图片，结果明确标记“模拟分析”。模拟数据和真实数据会累积到同一学生档案，制作方切换运行模式时应使用不同测试学生避免混淆。图片内容相同的试卷在同一学生、同一模式下只能计入一次。

## 真实模型

支持具有图片理解能力、兼容 Chat Completions 接口且支持 `response_format: json_object` 的服务。配置服务端环境变量后重新启动：

```sh
export MODEL_BASE_URL='https://你的服务地址/v1'
export MODEL_NAME='你的多模态模型名称'
read -s MODEL_API_KEY
export MODEL_API_KEY
python3 demo/server.py
```

`read -s` 执行后输入密钥并按回车，输入内容不显示。密钥只通过环境变量使用，前端和数据库不保存密钥。真实分析会把试卷、学生姓名、当前档案、相关知识点和提示词发送到你配置的服务。

## 档案更新规则

- 仅 `incorrect` 且置信度 ≥ 0.75 的题目计入薄弱项。
- 新薄弱项从 2/5 开始；同一试卷中同一知识点增加一次严重程度，最高 5/5。
- 每道符合条件的错题分别保留证据、题号和建议。
- 正确、无法判断及低置信度题目保存在分析记录中；不自动降低严重程度。
- 每张试卷以事务原子保存分析记录和档案更新；失败不更新档案。
- 保留原始图片、实际使用的提示词、模型名称、更新前后档案，便于后续回溯。

## 当前范围

默认数学知识库只有 6 个知识点，适合验证流程，可自行扩充。PDF 暂不支持，可先将页面导出为图片。没有登录、后台任务或在线部署，模型调用期间页面保持等待。服务只供本机演示；长时间运行和多人使用需要后续增加后台队列、访问权限及文件存储。
